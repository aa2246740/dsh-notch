# DSH Notch 0.3.2 — DeepSeek Harness 0.1.7-rc.2

发布日期：2026-09-27。社区插件正式适配 DSH **0.1.7-rc.2 Desktop / Web**。配套同步助手为 **dsh-notch-focus 0.1.1**。

## 这次更新

- 修复在 DSH 前台打开已完成会话后，Notch 未读状态不消失的问题。桌面代理转发和 Web 同源请求均可同步，后台页面不能代替用户确认已读。
- 使用 RC2 的会话导航、未读状态和主视图保留接口；支持 API 创建的自定义会话 ID，单个自定义 ID 不再阻断整批侧栏同步。
- 普通、嵌套和后台子代理按主任务归并；用户手动 fork 的会话独立保留。子任务运行时不会提前清除主任务结果。
- 保留完整弹性边缘收纳：二维拖拽、端部变细、柔性拉伸上限、松手回弹，以及隐藏后遇到新完成、错误或待回答问题时自动弹回。
- 修复 Desktop 传入连接文件时被误判为演示模式而偏离屏幕边缘的问题；原生唤起优先使用官方桌面版。
- 辅助程序跟随 Host 生命周期，接管已有进程时检查身份，更新时避免重复启动。
- Host 与同步助手都提供官方 Bundle 声明和预编译包。安装无需 DSHX；源码构建保持在外部插件目录。

## 验证范围

本机 RC2 桌面环境（DSH Studio，使用官方 RC2 Host / Web）已完成真实模型任务验证：任务完成后 Notch 显示未读；随后从 DSH 侧打开该会话，Notch 清除该条结果，同时保留其他运行任务。验收数据与连接配置保留在本机，不随仓库发布。

本次发布检查全部通过：

- `npm test`：67 项通过，覆盖 RC2 客户端导航、桌面 / Web 已读同步、自定义会话 ID、请求边界、子代理归属和辅助进程托管。
- Host 预编译构建、同步助手类型检查与构建、两个插件的 `dshx check` 通过。助手在隔离目录使用 npm 公共依赖重新构建，产物与本机构建一致，仓库附有依赖锁文件。
- 10 组原生回归通过：motion、geometry、outcome、presentation、edge-dock、idle、scrollbar、expanded-height、host-lifetime、desktop-launch。桌面入口的屏幕边缘间隙为 0 pt。
- 最终原生压缩包解压后通过 `IDLE_RESOURCES=10/10`、签名完整性检查和隔离生命周期测试：临时 HTTP 故障时保持运行，测试宿主退出后正常关闭。
- 两个插件包包含 Bundle patch 与预编译入口；助手包含 lazy-CJS 客户端。归档检查未发现安装脚本、凭据或本机绝对路径。

原生程序面向 macOS 14+ / Apple Silicon；没有 Intel 预编译包或本轮跨架构验收。发布包不包含 Developer ID 公证。桌面客户端 HMR 和所有第三方壳的行为不在本次兼容承诺内；安装或更新后按插件管理器提示完成加载并重新打开页面。
