# DSH Notch 0.3.3 — DeepSeek Harness 0.2.0-rc.1

源码适配官方 `dsh-v0.2.0-rc.1`（SHA `4878cdabd87d4041bdaff61d04c966883b9fd07a`，包 `@deepseek-ai/dsh@0.2.0-rc.1`）。Host 插件升到 **0.3.3**，同步助手升到 **dsh-notch-focus 0.1.2**。

`@deepseek-ai/dsh` 与同线 `@deepseek-ai/dsh-*` peer 为 `>=0.2.0-rc.1 <0.2.1`，与 DSHX 0.9.2 相同。该范围接受 `0.2.0-rc.1` 和稳定版 `0.2.0`，拒绝 `0.2.0` alpha，也拒绝 `0.1.7-rc.2`。

对照 `dsh-v0.1.7-rc.2`，Notch 实际调用的 Host 会话、Web 路由、提问、审批、任务、Home 路径，以及助手使用的 `openSession`、`sessionStatus.completionUnread`、侧栏快照，源码签名没有变化。`src/board.ts` 的构造函数没有因为这次 peer 调整而改写。

本记录不包含 macOS Notch 视觉验收，也不打 tag、不发布 npm。已发布的 v0.3.2 仍是 0.1.7-rc.2 安装包。
